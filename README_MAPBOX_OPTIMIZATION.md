# Mapbox Optimization — integrare asistată

În Grafic, recalcularea manuală poate consulta Mapbox Optimization pentru maximum 10 intervenții rămase, plus plecare și destinație finală.

Condiții: token public Mapbox, GPS complet, minimum 3 execuții pe locație, punct final definit. Mapbox propune doar dacă distanța rutieră calculată scade; utilizatorul aprobă explicit înainte de salvare. Recalcularea automată păstrează algoritmul Learning existent.

Nu sunt modificate GitHub sau APK. Testele Flutter și Mapbox live nu au fost executate în acest mediu.
