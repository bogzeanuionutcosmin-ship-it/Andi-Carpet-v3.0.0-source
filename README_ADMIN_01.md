# Admin Panel – navigare mobilă

- Selector de secțiuni vizibil direct pe fiecare pagină Admin pe mobil; nu mai depinde exclusiv de meniul lateral.
- Acces rapid la Echipe, Membri, Locații, Grafice, Financiar, Notificări, Audit, Drepturi și Setări din Dashboard.
- Navigarea desktop și meniul lateral existente sunt păstrate.
- Nu au fost schimbate permisiunile Firestore și nu s-au modificat datele utilizatorilor.
